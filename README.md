# Mi Grabador v3 — Videollamada, chat y grabación

Página en línea: https://jhonnyvasquez240973-coder.github.io/tuusuario.github.io/

## Uso rápido
1. Doble clic en `Iniciar_grabador.bat` (Windows). Crea una sala, abre tu navegador ya conectado y copia la invitación.
2. En la ventana del `.bat` elige **W** (WhatsApp) o **C** (correo) para enviar la invitación.
3. También puedes enviarla desde la página: botones **Enviar por WhatsApp** y **Enviar por correo**.
4. Tu invitado abre el enlace, permite cámara y micrófono y entra solo a la videollamada y al chat.

No hace falta ngrok: la invitación apunta a esta página publicada. Si la página en línea no responde,
el `.bat` usa un servidor local con Python como respaldo (necesita `index.html` junto al `.bat`).
